# Movement Lens media notes

The README screenshots show the working Movement Lens interface with the
developer's private prepared Marcelo example. The screenshot files are selected
presentation assets; no downloadable source match or populated dataset is included.

| Asset | What it shows |
| --- | --- |
| `clusters.png` | All 290 usable independent windows grouped into two suggested clusters |
| `cluster-inspection.png` | A typical clip beside its aligned player-scaled pose and category review |
| `match-timeline.png` | Coverage-limited cluster occurrences in both source halves |
| `cluster-explanation.png` | A real saved Microsoft Foundry explanation for the displayed cluster/category |
| `evidence-pack.png` | Local packaging of the selected cluster's complete evidence and representative clips |

The explanation screenshot displays an immutable, previously generated result
whose saved evidence signature matches the current match, cluster and category.
Its original request used four three-frame image strips and the four read-only
cluster/research tools. No new model call was made to capture these screenshots.
It is an AI draft, not an independently validated clinical finding.

The shared `../diagrams/touchline-movement-lens.svg` illustration is original
schematic artwork using text and vector shapes. It contains no broadcast imagery,
cloud identifiers, private source paths or real dataset rows.

Football imagery visible in the app remains third-party material. These media
notes document provenance; they do not grant redistribution rights for the
underlying broadcast. The screenshots are not sample data for reproducing the fit.
Touchline's older demo uses a different saved match; the two recordings do not
claim to show the same exported ZIP moving between applications.

Editable video compositions, raw screen recordings, music and sound-effect
production assets stay in ignored local `brag-output/`. Only explicitly selected
public presentation assets belong in this directory.

## V2 demo and showcase images — October 28, 2026

`movement-lens-demo.mp4` is the selected **104-second, 1920×1080, 30 fps** demo.
`demo-poster.jpg` is its opening preview. The six numbered PNGs in
[`showcase/`](showcase/README.md) are 1920×1080 presentation cards using actual app
captures and original layout/graphics. [Upload captions](showcase/upload-captions.md)
describe each image. The original 110-second video remains preserved locally.

The V2 recording uses the existing prepared workspace and the saved real Foundry
result described above. It does not show a newly generated AI response. The
portable report is a genuine local export with all 116 selected-cluster members
and four representative clips. Azure report storage is optional; this recording
does not demonstrate a cloud upload. The Touchline bridge illustrates the shared
ZIP format using a different saved match.
